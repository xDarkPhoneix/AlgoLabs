## Q7. Shell Script: Assignment Checker | Marks: 14

Create the sample data with these commands (run them from the main folder):

```bash
mkdir -p commands/students/riya commands/students/amit
printf 'Q1 done\nQ2 done\n' > commands/students/riya/assignment1.txt
printf 'Q1 done\nQ2 done\nQ3 done\n' > commands/students/riya/assignment2.txt
printf 'Q1 done\n' > commands/students/riya/assignment3.txt
printf 'Q1 done\n' > commands/students/amit/assignment1.txt
printf 'Q1 done\nQ2 done\n' > commands/students/amit/assignment2.txt
```

The script `scripts/check_student.sh` is already created and empty. Write it so that it takes the path of one student folder as its argument:

```bash
./scripts/check_student.sh commands/students/riya
```

The script must, in this order:

1. **Check the folder:** If no folder path is provided or the given folder does not exist, print `Error: student folder not found` to standard error and exit with status `1`.

2. **Check the assignment files:** Store the names `assignment1.txt`, `assignment2.txt`, and `assignment3.txt` in an **array**. Use a **`for` loop** to check whether each file exists inside the given folder.
   - If any file is missing, print `Missing: <filename>` to standard error and exit with status `1`.
   - Do not print anything to standard output in this case.

3. **Display the results:** If the folder and all three files exist, print the folder path and the number of lines in each assignment file in the specified format. Exit with status `0`.

```text
Student: commands/students/riya
assignment1.txt: 2
assignment2.txt: 3
assignment3.txt: 1
```

Make the script executable and run these three tests from the main folder. Each test saves standard output in `.out`, standard error in `.err` and the exit status in `.status` (all nine files are already created):

```bash
# Test 1: a student with all three assignments
./scripts/check_student.sh commands/students/riya > outputs/q7_test1.out 2> outputs/q7_test1.err; echo $? > outputs/q7_test1.status

# Test 2: a student with a missing assignment
./scripts/check_student.sh commands/students/amit > outputs/q7_test2.out 2> outputs/q7_test2.err; echo $? > outputs/q7_test2.status

# Test 3: no argument
./scripts/check_student.sh > outputs/q7_test3.out 2> outputs/q7_test3.err; echo $? > outputs/q7_test3.status
```
